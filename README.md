# Taskflow — Advanced Task Manager

A professional Kanban-style task manager built with vanilla **HTML, CSS & JavaScript** — no frameworks, no backend, fully client-side with `localStorage` persistence.

## Features

- 🗂️ **Kanban board** — To Do / In Progress / Done columns with native drag-and-drop
- 📋 **List view** — toggle between board and list layouts
- ➕ **Full CRUD** — create, edit, and delete tasks via a modal form
- ✅ **Subtasks / checklists** inside each task, with a live progress bar
- 🚦 **Priority levels** (High / Medium / Low) with color-coded badges
- 🏷️ **Categories** — auto-generated filter list from your own tags
- 📅 **Due dates** with automatic overdue detection
- 🔍 **Live search** across task titles and descriptions
- 📊 **Stats dashboard** — animated radial completion ring, total/completed/overdue counts
- 💾 **Persists in localStorage** — your tasks survive a page refresh
- 📱 Fully responsive, dark professional UI

## Tech Stack

- HTML5
- CSS3 (custom design system, CSS variables, no framework)
- Vanilla JavaScript (drag-and-drop API, localStorage, DOM manipulation)

## Run locally

Just open `index.html` in a browser — no build step, no dependencies.
